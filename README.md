# Missione Luxia

Il gioco finale dello Strategy Day. Si gioca dal telefono, **senza account**.

- `index.html` – il gioco (giocatori, proiettore `#host`, domande `#admin`)
- `config.js` – qui va il link della "base" (lo script Google)
- `Code.gs` – la base: salva giocatori, partita e domande (va su script.google.com, non su GitHub)

Pagine:
- Giocatori: `https://<utente>.github.io/missione-luxia/`
- Proiettore: `https://<utente>.github.io/missione-luxia/#host` (chiede il PIN)
- Domande e regole: `https://<utente>.github.io/missione-luxia/#admin` (chiede il PIN)
